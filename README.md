# 칩북 (ChipBook)

전자책 판매·열람 플랫폼 — 기획·디자인·개발·배포 1인 개발

🔗 서비스 URL: https://chipbook.net

## 기술 스택

- **Frontend**: Vanilla JavaScript, HTML5, CSS3
- **Backend**: Supabase (PostgreSQL, Auth, RLS)
- **배포**: GitHub + Vercel

## 주요 기능

- 이메일·소셜 로그인 (Supabase Auth)
- RLS 기반 유료·무료 콘텐츠 접근 권한 분리
- 전자책 등록·수정·삭제 관리자 페이지
- 시리즈·태그 기반 콘텐츠 분류 구조
- 전자책 콘텐츠 뷰어
- GitHub 연동 Vercel 자동 배포

## 개발 현황

- 핵심 기능 개발 완료 및 배포
- 결제 모듈 (토스페이먼츠) 연동 진행 중
